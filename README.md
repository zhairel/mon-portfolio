# Mon Zhairel B. Lingasa - Software Engineer Portfolio

Production Portfolio showcasing enterprise Laravel systems, financial billing platforms, school management infrastructure, and full-stack software engineering.

## 🚀 Tech Stack
- **Framework**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, CSS Variables (Light & Dark Theme)
- **Animations**: GSAP 3, ScrollTrigger, Lenis Smooth Scroll
- **Icons**: Lucide React

## 📦 Getting Started

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build
```

## 🌐 Systems Featured
1. **AMIS Family Payment System (AFPS)** - Multi-sibling tuition billing, automated SOA, and finance verification platform.
2. **AMIS Online Enrollment System (AES)** - Student onboarding, document verification, and admissions portal (`https://aes.amis.edu.ph/`).
3. **AMIS Central Portal & Digital Identity** - Unified role-based dashboard for students, teachers, and admins.
4. **AMIS Unified LMS & Digital ID** - QR-based identity and academic management infrastructure.
5. **Campus Network & IT Infrastructure Hub** - Active Directory, Microsoft 365, and institutional IT operations.
6. **Integrated Tuition & Financial Ledger** - Real-time student ledger and cashier transaction engine.
